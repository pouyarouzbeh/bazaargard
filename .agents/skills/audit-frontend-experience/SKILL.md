# Audit Frontend Experience

Read [design system](../../../agents/shared/design-system.md), [accessibility](../../../agents/shared/accessibility-localization.md), [overlays](../../../agents/shared/overlays-and-interactions.md) and [experience checklist](references/experience-checklist.md).

Inspect the requested journey and style owner, expanding only for concrete dependencies. Assess one primary action, hierarchy, neutral color budget, truthful price/hour/identity claims, optional complexity, draft preservation and recovery. Review mobile, keyboard, light/dark and reduced-motion states.

When improvements are requested, fix the narrowest durable owner and remove conflicting rules. Preserve live API authority and existing feature access. Browser-check real behavior; source inspection alone does not prove usability. Do not claim five-user research without actual participants.

Finish with `$verify-static-frontend` and a dated changelog; distinguish automated checks, rendered interaction and unresolved real-device/model evidence.
