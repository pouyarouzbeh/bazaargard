# ButterPop.js license

The shared toast implementation adapts queueing, timed progress, pause, duplicate-prevention, and stable-update behavior from [ButterPop.js](https://github.com/Ayushx309/ButterPop.js) version 1.0.4. Its visual layer was rewritten for React, semantic project tokens, RTL/LTR, accessibility, and reduced motion.
