# حذف معرفی تکراری دستیار

- تاریخ: 2026-10-23، Asia/Tehran؛ فقط لوکال.
- درخواست: حذف «بازارگرد / آماده کمک» و آیکون کنارش از سربرگ گفت‌وگو.
- تغییر: بلوک معرفی، دکمهٔ «نمایش نتایج»، کل سربرگ و CSS بلااستفادهٔ آن حذف شدند. بالای گفت‌وگو نوار خالی باقی نمی‌ماند. وضعیت پاسخ همچنان در پیام بارگذاری نمایش داده می‌شود و بخش نتایج از ناوبری اصلی در دسترس است.
- فایل‌ها: `frontend/src/main.jsx`، `frontend/src/style.css`، این گزارش و index.
- اعتبارسنجی: بیلد Vite و بودجه gzip موفق؛ JS برابر 173.6 KiB و CSS برابر 19.4 KiB. صفحهٔ لوکال در دسکتاپ بررسی شد: متن «آماده کمک»، دکمهٔ «نمایش نتایج» و سربرگ داخلی گفت‌وگو وجود ندارند. حذف معرفی در موبایل نیز مشاهده شد. منطق داده و API تغییر نکرده‌اند؛ تست جدید لازم نیست.
- انتشار/commit/push انجام نشده؛ داده‌ها و تغییرات قبلی حفظ شده‌اند.
