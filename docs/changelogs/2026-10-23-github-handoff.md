# آماده‌سازی مخزن اختصاصی GitHub

- تاریخ: 2026-10-23، Asia/Tehran.
- مقصد درخواست‌شده: `pouyarouzbeh/bazaargard`، شاخهٔ `main`.
- README اختصاصی فارسی با معرفی نسخه، قابلیت‌ها، Windows/Linux/macOS، داده، تنظیم مدل، توسعه، بررسی‌ها، مستندات و خلاصه انگلیسی نوشته شد. انتساب منبع و مجوزها حفظ شدند.
- `.env.example` با تنظیمات بدون کلید و نشانی لوکال سازگار شد. بخش فرانت CI از `npm run check` استفاده می‌کند.
- سورس و تغییرات لوکال UI/اسکیل‌ها در تحویل هستند؛ داده‌ها، `.env`، کش، بیلد و محیط مجازی excluded هستند.
- مخزن مقصد هنگام بررسی تنها یک README اولیه داشت؛ تاریخچهٔ آن و منبع اصلی در ادغام حفظ می‌شود. force-push جزو این تحویل نیست.
- انتشار نرم‌افزار روی سرور درخواست نشده است. نتیجه push و شناسه commit در پاسخ تحویل گزارش می‌شود؛ این گزارش وضعیت آماده‌سازی سورس را ثبت می‌کند.
- اعتبارسنجی آماده‌سازی: README و لینک‌های محلی آن بررسی شدند؛ `npm --prefix frontend run check` شامل مستندات، ۷۲ جفت کنتراست، ۶ تست، بیلد و بودجه خروجی موفق بود. Gitleaks 8.30.1 پس از تطبیق SHA-256 روی تاریخچه و snapshot کامل index اجرا شد و موردی نیافت. هیچ فایل اجرایی/دیتاست/.env در index نیست.
- بررسی whitespace روی سورس موفق است. چهار hard break عمدی Markdown در سند UX ورودی کاربر حفظ شده‌اند. سه شکست Windows بک‌اند از مرحله آماده‌سازی در راهنمای اجرا ثبت‌اند؛ backend تغییر نکرده و این نوبت دوباره اجرا نشده است.
